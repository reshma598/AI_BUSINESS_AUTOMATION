# AI_BUSINESS_AUTOMATION
An AI-powered business automation web application that integrates HRMS, CRM, Project Management, and Email Automation into a single workspace. Built using Python, FastAPI, SQLite, and Gemini API to automate routine business workflows, screen resumes, score leads, generate project plans, and provide AI-assisted business insights.
AI Business Automation Agent

Project Overview

AI Business Automation Agent is an AI-powered web application developed to simplify and automate routine business operations. It combines Human Resource Management (HRMS), Customer Relationship Management (CRM), Project Management (PMS), and Email Automation into a single centralized workspace.

The application uses Gemini AI to provide intelligent assistance for resume screening, lead scoring, project planning, and business-related queries.

Key Features

1. HRMS – Human Resource Management

- Employee record management.
- Attendance management.
- PDF resume screening using AI.
- Resume analysis and candidate evaluation.

2. CRM – Customer Relationship Management

- Customer information management.
- Lead management.
- AI-powered lead scoring.
- Lead prioritization.

3. Project Management System

- Project creation and management.
- Task tracking and prioritization.
- AI-generated project plans.
- Task planning assistance.

4. AI Assistant

- Centralized conversational chatbot.
- Database-backed business queries.
- AI-powered responses using Gemini API.
- Routes supported questions to relevant modules.

5. Email Automation Agent

- Email drafting.
- Review and approved email sending.
- Email history management.

6. Agent Activity Centre

- Tracks completed requests.
- Maintains activity logs.
- Displays operation results and activity summaries.

7. Authentication and Dashboard

- User registration and login.
- Session-based authentication.
- Admin access.
- Centralized dashboard.

System Architecture

1. User interacts with the web interface.
2. Frontend sends API requests to the FastAPI backend.
3. Backend processes requests and communicates with SQLite.
4. Gemini API provides selected AI-powered capabilities.
5. Results are returned to the frontend.
6. Completed activities are recorded in the Activity Centre.

Project Implementation Stages

1. Project setup and FastAPI application.
2. SQLite database and business tables.
3. Dashboard and central chatbot.
4. HRMS and resume screening.
5. CRM and AI lead scoring.
6. Project management and AI-generated plans.
7. Agent Activity Centre.
8. Email drafting and automation.
9. Registration, login and session management.
10. Agent routing and integration testing.

Future Enhancements

- Advanced natural-language business action execution.
- Stronger role-based access control.
- Improved security and audit controls.
- Automated testing.
- Production deployment and persistent hosting.
- Database backups.

Project Objective

To develop a centralized AI-powered business automation platform that reduces manual work, improves workflow management, and supports faster business decision-making.
